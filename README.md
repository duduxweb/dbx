# DBX — Playlist consolidada

Este repositório gera uma única playlist M3U a partir das listas públicas do repositório [Ramys/Iptv-Brasil-2026](https://github.com/Ramys/Iptv-Brasil-2026).

O GitHub Actions atualiza a playlist diariamente e publica o arquivo como ativo de uma Release, mantendo uma URL estável para importar no player IPTV.

Arquivo final: `playlist.m3u`.
